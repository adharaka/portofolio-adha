# Portofolio Adha Raka Firmansyah

React + Vite. Isi teks ada di `src/data.js`, gambar di `public/images/`.

## Jalankan lokal
    npm install
    npm run dev

## Deploy ke Netlify
Opsi 1, drag and drop: jalankan `npm run build`, lalu seret folder `dist` ke https://app.netlify.com/drop
Opsi 2, lewat Git: push ke GitHub, di Netlify pilih "Import from Git". Pengaturan build sudah ada di `netlify.toml` (build: `npm run build`, publish: `dist`).
